# V4 角色与表情方向：A 精致柔软 Q 版

记录日期：2026-10-17。当前制作基准为用户已选的 **A 精致柔软 Q 版**。可爱度是用户明确优先的目标；原作研究用于辅助设计，不能压掉软萌感，也不能否定用户明确指定的幻想动作与表情。旧 V3 的较端正方向未获用户认可，不作为本轮艺术基准；此前 agent 的意见不等于用户已经认可画风。

## 可爱度与角色边界

以下为本项目的创作推断与用户方向，不是原作的精确比例设定。

- 保持 A 的柔软圆脸、精致但简洁的五官、短小圆润身体和温暖亲近感。不要为了显得认真而将脸拉长、身形拉直或把嘴固定成无表情的细线。
- 认真可以通过视线、上眼睑和很轻的眉形变化表达；不用变成冷淡、严厉或成人化的神态。
- 跑步表情以用户最新选择为准：回到最初原版 `nagisa-furukawa/spritesheet.webp` 的跑步行，使用双眼 `><` 的努力眯眼，表现很累仍努力跑。沿用当前 A 画风；此前研究对跑步闭眼的禁用建议及睁眼专注要求在此撤销，不能覆盖用户选择。
- 软萌表情仍须有情境区别。温暖小笑、安静等待、轻微失落和专注查看不能只靠随机睁闭眼互换。
- 失落保持可爱，但不可继续笑或 wink；也不需要夸张崩溃大哭。等待按用户新参考使用竖线眼呆萌坐姿，这是明确选择，不能以“应睁眼回应”或“不能呆坐”为由改回旧方案。
- 团子大家族使用有两条竖眼的柔软椭圆毛绒形象，避免无脸糖球、发亮食物球或串在棍上的日式点心。
- 等待和跳跃的最新指定动作优先于旧研究建议：等待时双手把粉团子轻轻拉到嘴边、团子变长，身后有绿、蓝、橙团子堆；跳跃时渚坐在大团子上，被大团子托着飞起来。两者均保持 A 画风，不以缺乏原作习惯证据为由删除或改成抱小团子跳。

## 全动作表演方向

| 状态 | V4 推荐表情与动作 | 避免 |
| --- | --- | --- |
| idle | 延续 A 的软圆脸与短身，温暖小笑，睁眼有亲近回应，轻抱团子与轻微呼吸。 | 为了端正而拉长身体；僵直坐姿；频繁大幅睁眼闭眼切换。 |
| running-right | 小步轻跑、低抬膝、窄步幅，书包贴近身体，躯干仅微前倾；使用用户选择的最初原版双眼 `><` 努力眯眼，表达很累仍坚持跑，统一 A 的软萌画风。 | 腾空大跨步、高抬膝、大幅甩臂或甩包；改成开心弯弧笑眼、单眼 wink、愤怒瞪眼或重新强制睁眼。 |
| running-left | 与右跑使用相同 `><` 努力眯眼、疲累仍坚持的神情，以及同样克制的幅度和角色比例。 | 左右方向变成不同脸型、年龄感或不同表情含义；单侧变成笑眼、wink 或愤怒脸。 |
| waving | 温暖小笑，手在脸侧或肩旁轻柔招呼，动作短小亲近，可带一点羞涩。 | 大幅高举手臂；抛媚眼；一直闭眼而失去回应感。 |
| jumping | 按用户指定，渚坐在大团子上，由大团子托着飞起来；明确保留坐乘关系和托举升空的幻想感，统一 A 的软萌画风。 | 改成站着抱小团子跳；删除幻想托飞动作；人物变成独立蹦跳或把身体拉长。 |
| failed | 保留 A 的软萌圆脸，忧眉、收嘴、视线稍低，表达轻微受挫或担心；可有重新鼓劲的余地。 | 开心笑、wink、赌气鼓腮、持续嚎哭或过度病弱感。 |
| waiting | 按用户新参考，竖线眼呆萌坐姿；双手把粉团子轻轻拉到嘴边，使粉团子变长；身后保留绿、蓝、橙团子堆，统一 A 画风。 | 改回大睁眼、wink 或普通抱团子放膝上；漏掉轻拉到嘴边与变长的动作；漏掉身后绿蓝橙团子堆；将毛绒画成食物串。 |
| running | 延续小步、低抬膝、微前倾、贴身道具与双眼 `><` 努力眯眼；一次循环方向和动机一致，保留很累仍努力的可爱感。 | 同一循环突然左右掉头；幅度大于左右跑；变成笑眼、wink、愤怒脸或无动机睁眼。 |
| review | 专注的半垂眼，看向屏幕，嘴小而自然；保留柔软可爱的脸型与体态，电脑作为桌宠改编道具。 | 眼睛看观众而屏幕只是摆设；冷脸皱眉；频繁 wink；高速黑客式夸张敲键盘。 |

## 小步跑的适配理由

小步、低抬膝和最初原版 `><` 努力眯眼均是用户明确选择。疲累仍努力的表情与轻柔小步同时保留，不能为了显得轻松而消除疲累感，也不能借疲累把步幅重新夸大。这是桌宠创作选择，不把“体弱”直接画成无力、疼痛、病态或不能正常奔跑。

## 后续独立审阅边界

源图到位后，独立检查表情含义、视线对象、动作幅度与 A 的可爱度是否延续；跑步是用户指定的双眼 `><` 例外，不以看向行进方向或睁眼作为通过条件。左右跑和 running 均须保留努力眯眼，能读出很累仍坚持，而非开心笑眼、单眼 wink 或愤怒脸，同时保持小步低抬膝。

waiting 按竖线眼呆萌表情验收，不要求改回平和睁眼；检查粉团子是否由双手轻拉到嘴边并变长，以及身后绿、蓝、橙团子堆是否保留。jumping 检查人物是否坐在大团子上、由大团子托着飞起，不用原作习惯否定幻想动作，也不建议改为抱小团子跳。

修正优先针对实质问题，例如 failed 仍在笑、review 不看屏幕、跑步幅度仍过大或丢失原版努力眯眼、waiting 缺少指定动作/竖线眼/团子堆、jumping 丢失坐乘托飞关系，或毛绒变点心。不要让旧研究建议或 V3 的严格端正感覆盖用户最新选择，也不要因某个 agent 放行就声称艺术效果已由用户验收。制作与整套审阅应继续进行，不因主观的无限细改而停住任务。
