# V4 软萌画风审阅

## 唯一美术基准

用户选中的 A 在本发布版本中的母版文件为 [`sources/idle.png`](sources/idle.png)。本轮全部动作以 A 的可爱度、圆脸、眼形、暖棕高光和柔软染色为准；V4 合图为 [`style-comparison.png`](style-comparison.png)。历史选择发生在 V3 阶段，但发布文件引用仅指向本版本随附素材。

原作研究只辅助角色身份识别，不以“原作更严肃”为理由减弱用户已选的软萌程度，也不能否决用户明确指定的幻想动作或简化表情。V3 的 2.8 头身和硬块赛璐璐不是 V4 的强制标准；不能拿它们覆盖 A。用户对跑步 `><`、waiting 竖线眼和骑团子跳跃的具体要求优先于通用眼形及原作习惯建议。

## 固定视觉规格

| 项目 | 必须延续 A 的内容 | 漂移判据 |
| --- | --- | --- |
| 脸与头型 | 宽圆脸、饱满面颊、蓬松大头；小下巴融入圆弧 | 变成长尖脸、瘦削脸、成熟少女头身，或每个动作换一种头宽 |
| 眼形 | 很大的柔圆椭圆眼；深暖棕上睑；睁眼时保有充足的虹膜面积 | 变成 V3 的较细眼、尖锐吊眼、细长侧瞳或完全不同的睫毛规则 |
| 虹膜 | 上深棕、下蜂蜜金的柔和渐变，深棕瞳孔，圆白主高光和小辅高光 | 灰瞳、纯橙平涂、亮金金属瞳；每行动作的高光和瞳色各自变化 |
| 默认嘴 | 小而柔的 U 形闭口笑，位置偏低，嘴部留白足 | 大张口招牌笑、猫嘴、成熟嘴唇，或无原因每帧换嘴型 |
| 肤色与腮红 | 奶油桃色肌肤，桃粉柔晕与细斜线腮红，光滑柔软 | 冷灰皮肤、硬红圆腮、厚重鼻影或过度成人化鼻梁 |
| 头发底色 | 暖栗棕至焦糖棕；深棕轮廓 | 偏灰褐、深红、艳橙或与 A 明显不同的冷棕 |
| 头发高光 | 宽而柔的杏金高光带，少量尖端渐细的短亮束；发尾柔圆分束 | 缺少高光导致整头发哑平，或出现塑料镜面白条、过细噪乱发丝 |
| 双呆毛 | 分开的两根弧形呆毛，暖棕线条和高光与头发相连 | 变成闭合兔耳、黑色铁丝、额外第三根；不能靠随意复制修补改变根部 |
| 染色和线稿 | 暖深棕干净线条，柔软的有色阴影与轻微明暗渐变 | 退回硬块平涂、黑色粗描边，或变成 3D 塑料渲染 |
| 制服 | 暖奶油米白外衣、酒红领/袖线、深蓝内领与裙、白袜棕鞋；沿用 A 的细节层级 | 动作间衣服从淡黄变灰白；领口、袖线或裙色改体系 |
| 团子 | 柔粉色、圆软体积、桃粉腮红；普通抱持小团子以竖线眼为基础，用户参考的幻想状态按各自形象保留 | 无参考依据地在同一动作循环中更换道具五官或材质；不能以常态小团子规则否决用户指定的大团子幻想动作 |

## 表情审阅边界

- idle：保留 A 的温柔可爱小笑与大椭圆眼。
- waiting：**以用户参考图的坐姿和竖线眼为准**；粉团子举到嘴边，形成软糯、略拉长的形状，背后有绿、蓝、橙色团子叠堆。竖线眼是用户主动选择的简化表情，不得以 A 平常是大眼或原作没有该表情为由否决；圆脸、暖栗棕杏金高光和柔软染色仍统一 A。旧的普通睁眼抱团子侧坐方案已经被覆盖。
- failed：仍是同一张圆润大眼脸，通过眉内侧上抬、上睑微垂和小下弯口表达失落。不能换成尖脸、灰脸，也不能在循环中忽然开心笑。
- review：保留柔软可爱度，目光落向电脑／书页，嘴型中性或轻微思考。不能把专注画成愤怒或不耐烦。
- jump：**按用户新要求改回坐在大粉团子上弹起、飞起来的感觉**。骑坐姿势和大团子的弹跳是核心轮廓，脸与眼沿用 A，可有轻微惊喜的小圆口。不能拿原作行为习惯否决这种用户指定的幻想动作，也不能用原先站立抱小团子的跳跃源代替。
- running：**用户最新明确选择最初原版的 `><` 眯眼、努力跑，即使累也保持小步前进。** 这是本轮跑步神情的直接标准，不能再以“所有跑步都要睁眼”或“闭眼必然 OOC”否定它。闭眼应画成有力而柔软的 `><` 折线／弧线，不是困倦下垂眼，也不是开心大笑。眉毛和小嘴表达努力、轻微疲惫，不能变成生气或得意；小步步态由动画流程保持。脸型、眼周结构、暖栗棕高光和柔软染色仍统一 A。闭眼时自然不显示虹膜，不能为了套用 A 的睁眼模板强塞瞳孔；其他状态继续按各自神情审阅。
- waving：柔和、稍羞涩的小幅挥手；可以笑得比 idle 明显，但不能突然变成另一套表情包脸。

## 后续放行方法

先逐图核对与 A 的脸型、眼神、头发高光和染色是否一致，再看动作表情能否读对。技术透明度、抠图与步态另行验收；不把极低透明度的彩色边缘误当作源图画风差异。缩到实际帧格尺寸后仍需保留眼形与金棕虹膜的识别，不能靠放大图才成立。

### 用户修订的跑步验收优先级

跑步以“最初原版的 `><` 努力神情 + A 的画法”为唯一合并目标。该直接要求优先于先前原作研究中关于跑步睁眼的建议，也优先于 V3 已放行的睁眼跑版本。最终努力眯眼源已实际查看并通过下节检查；不能把闭眼本身列为返工理由。

### 用户修订的 waiting／jump 验收优先级

waiting 最终源已具备：用户参考坐姿、竖线眼、嘴边软糯拉长的粉团子、身后绿蓝橙团子叠堆，以及 A 的暖亮柔软画法。jump 最终源是坐在大粉团子上弹起的幻想动作，而不是人抱小团子直立跳。原作研究、V3 表情规则和先前旧源放行均不得覆盖这些直接要求；最终源均经过实际查看后放行。
